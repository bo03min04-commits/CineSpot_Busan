# 포스터 기준 이미지 등록

이 폴더에 영화 제목별 하위 폴더를 만들고 해당 영화의 포스터 이미지를 넣으세요.

예시: `backend/posters/국제시장/main.jpg`, `backend/posters/국제시장/teaser.png`

JPG/JPEG/PNG/WEBP를 지원합니다. 여러 포스터를 등록하면 해당 영화의 최단 이미지 해시 거리를 사용합니다.

이 배포본에는 저작권 및 이용 허락이 확인되지 않은 포스터 원본을 포함하지 않습니다.
기준 이미지가 없으면 포스터 자동 인식은 작동하지 않습니다.
해당 촬영지 API에 등록된 영화만 등록하려면 `/api/all-filming-locations`의 `movie` 값 목록을 확인하세요.

서로 다른 디자인의 포스터를 찾으려면 각 디자인을 직접 등록해야 합니다.
