# CineSpot 부산 — 대표 명소 큐레이션 + 이전 추천 코스

## 적용
기존 파일을 백업한 뒤 ZIP의 두 파일만 교체하세요.
- `src/App.jsx` → `D:\cinespot-busan-starter\src\App.jsx`
- `src/style.css` → `D:\cinespot-busan-starter\src\style.css`

`main.jsx`, `backend` 폴더, 기존 `.env` 파일은 수정하지 마세요.

백엔드/프론트엔드 실행:
```powershell
# 터미널 1
cd D:\cinespot-busan-starter\backend
python -m uvicorn main:app --reload --port 8000

# 터미널 2
cd D:\cinespot-busan-starter
npm run dev
```

## 변경 사항
1. 왼쪽 `이전 검색 기록` 대신 **이전 추천 코스**. 단순 검색은 기록하지 않고 **주변 장소 선택 후 ‘선택한 장소로 코스 만들기’**를 눌렀을 때 자동 기록합니다. 코스 클릭 시 이전 추천 결과(선택한 장소, 지도, 방문 순서)를 다시 열 수 있습니다.
2. **저장한 코스**는 명시적으로 `코스 저장하기`를 눌러 보관한 코스만 포함합니다. 이전 추천 코스를 지워도 저장한 코스는 유지됩니다.
3. **새 채팅**은 처음 영화 검색 화면으로 돌아갑니다. 기록 및 저장 코스는 보존됩니다.
4. `국제시장`: 부산시 관광 자료로 확인한 **꽃분이네 1곳**만 대표 명소로 표시합니다.
5. `변호인`: 부산시 관광 자료의 **절영해안산책로 1곳**을 연계 명소로 표시합니다. 영화의 직접 촬영 장소로 확인되는 곳은 흰여울문화마을 일대이므로, 절영해안산책로 자체의 촬영 여부는 단정하지 않습니다.
6. 그 외 영화는 공공데이터에 검색 결과가 있어도, **대표 명소를 별도 검증/등록하기 전까지 촬영지 전체를 추천 목록에 나열하지 않습니다.** `src/App.jsx` 최상단 `FEATURED_FILM_LOCATIONS`에 근거를 확인한 장소를 추가하여 확장할 수 있습니다.
7. 촬영지를 누르면 **해당 항목 바로 아래에 지도 1개**가 열립니다. 다른 항목을 누르면 이전 지도가 닫힙니다. `코스 추천받기` 이후에만 주변 맛집·관광지·주차장 선택 화면이 표시되고, 추천 결과 지도에는 선택 장소만 나타납니다.

## 주의
- 영화 제목과 공공데이터 조회 기능은 기존 FastAPI 백엔드를 이용합니다.
- 위 2편의 대표 장소는 공공데이터 원본 목록을 그대로 출력한 것이 아니라 검증된 관광 자료를 참고해 별도로 선정한 명소입니다.
- 영화/관광지의 위치는 카카오 장소 검색 첫 번째 결과이며 실제 촬영 좌표로 확정된 것이 아닙니다.
- 주변 음식점, 관광지 및 주차장은 카카오 장소 카테고리 검색을 사용합니다. 방문 순서는 직선거리 기준이므로 도로교통, 대기시간, 주차 요금/가능대수는 반영하지 않습니다.
- `이전 추천 코스`와 `저장한 코스`는 브라우저 `localStorage`에 남습니다. 기기/브라우저를 바꾸면 자동 동기화되지 않습니다.
- React JSX 및 CSS 파싱은 확인했지만, 실제 사용자의 카카오 API 키/서버 환경에서 브라우저 통합 테스트는 수행하지 못했습니다.
