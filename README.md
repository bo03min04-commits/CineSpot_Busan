# CineSpot 부산 (CineSpot Busan)

> 부산에서 촬영된 **영화**와 실제 촬영 장소를 탐색하는 웹 서비스

## 1. 프로젝트 목적

CineSpot은 부산을 배경으로 촬영된 **영화의 촬영지**를 찾아보고, 방문할 수 있도록 돕는 서비스입니다. 영화 제목이나 포스터로 영화를 찾고, 촬영지의 위치를 지도에서 확인하며, 주변 관광지·맛집·주차장 정보를 탐색하는 것을 목표로 합니다.

## 2. 기술 구성

| 영역 | 기술/구성 |
| --- | --- |
| 프론트엔드 | React, Vite (`src/App.jsx`, `src/style.css`) |
| 백엔드 | Python, FastAPI (`backend/main.py`) |
| 지도·주소 | 카카오맵 JavaScript API 및 주소/좌표 확인 기능 |
| 촬영지 데이터 | 부산광역시·부산영상위원회 공공데이터 API |
| 포스터 인식 | 로컬에 등록한 포스터 이미지와 이미지 유사도 비교 (`backend/poster_matcher.py`) |
| 포스터 저장 | `backend/posters/<영화 제목>/` |

공공데이터 연결은 환경 변수 `MOVIE_API_GET_URL`, `MOVIE_API_KEY`, `CINEMAP_API_GET_URL`, `CINEMAP_API_KEY` 등을 사용합니다.

## 3. 주요 기능 및 변경 사항

### 3.1 영화 촬영지 공공데이터 연동 확대

- 부산영상위원회 **영화 속 부산정보 API**에 더해 **씨네맵 정보 API**를 함께 활용하도록 확장했습니다.
- 영화 제목으로 검색하면 공공데이터에 연결된 부산 촬영 장소를 표시하도록 했습니다.
- 대표 관광 명소가 따로 선정되지 않은 영화라도, 공공데이터에 촬영 장소가 있다면 해당 장소를 보여주도록 개선했습니다.
- 실제 주소나 좌표를 확인할 수 없는 장소는 지도에 임의로 표시하지 않도록 했습니다.
- 촬영지에서 주변 관광지·맛집·주차장을 찾는 기능을 유지·연결하는 방향으로 개발했습니다.

### 3.2 영화 전용 목록 정리

공공 API를 통해 생성된 목록에는 **총 429개 작품**이 있었으며, 영화 외에 드라마·OTT 시리즈·예능·교양 프로그램도 포함되어 있었습니다.

**제목 기준 1차 분류 결과**:

| 분류 | 작품 수 | 처리 방향 |
| --- | ---: | --- |
| 영화 후보 | 323 | 영화 검색 후보에 포함 |
| 비영화 | 74 | 검색에서 제외 |
| 추가 확인 필요 | 32 | 별도 관리 및 추가 검증 |
| **합계** | **429** | |

**중요:** 323편은 공식 영화 DB와 모든 작품을 일대일 대조하여 확정한 숫자가 아닙니다. 최종 서비스에서는 영화진흥위원회(KOFIC) 등으로 작품 유형·제작연도·감독 등을 검증하고, 동명이작을 구분해야 합니다. 부산 촬영 여부는 별도로 부산 촬영지 공공데이터와 대조해야 합니다.

분류 관련 파일:

```text
backend/data/
├── all_titles.json          # 수집된 전체 작품 제목
├── classification.csv       # 분류 결과
├── verified_movies.json     # 1차 영화 후보 목록 (파일명과 달리 전수 검증 완료는 아님)
├── excluded_titles.json     # 제외 작품
└── review_required.json     # 추가 확인 필요 작품
```

### 3.3 포스터 이미지로 영화 검색

- 외부 이미지 인식 API를 이용한 방식에서, 로컬에 저장된 **기준 포스터 이미지 비교 방식**으로 변경했습니다.
- 영화별 폴더에 포스터를 여러 장 등록할 수 있도록 구성했습니다.
- 포스터 파일명은 반드시 특정 이름일 필요 없이 이미지 확장자(`.jpg`, `.jpeg`, `.png`, `.webp` 등)를 사용할 수 있도록 하는 방향으로 개발했습니다.
- 이미지 업로드 → 영화 후보 표시 → 사용자가 제목 확인 → 영화 검색의 흐름을 사용합니다.
- 후보 목록에는 영화 제목만 표시합니다.

**기능 확인 사례:** `국제시장` 포스터 등록 후 해당 영화가 인식되는 것을 확인했습니다.

### 3.4 포스터 폴더 자동 생성·동기화

- `backend/sync_poster_folders.py` 스크립트를 추가했습니다.
- 실행 중인 백엔드의 영화 목록을 불러와 `backend/posters/` 아래에 영화별 폴더를 생성하도록 구성했습니다.
- 영화 목록을 TXT/CSV로 내보내는 기능을 구성했습니다.
- 백엔드가 실행되지 않은 상태에서 동기화를 시도하면 `[WinError 10061] 연결 거부`가 발생할 수 있습니다. **백엔드를 먼저 실행한 뒤 별도 터미널에서 동기화 스크립트를 실행**해야 합니다.
- 포스터 폴더는 매번 동기화할 필요가 없으며, 기존 이미지가 있다면 무분별하게 삭제하지 않도록 주의합니다.

예시:

```text
backend/
├── main.py
├── poster_matcher.py
├── sync_poster_folders.py
└── posters/
    └── 국제시장/
        ├── poster1.jpeg
        └── poster2.jpeg
```

**포스터 저장 경로:** `backend/posters/`

### 3.5 검색창 및 UI 수정

- 검색창의 `+` 버튼이 원형 버튼의 중심보다 아래로 치우쳐 보이던 문제를 수정했습니다.
- 문자 형태의 `＋` 대신 SVG 아이콘과 flex 중앙 정렬을 사용하도록 변경했습니다.

### 3.6 내 위치 기반 주변 영화 촬영지

- 브라우저 위치 권한을 이용해 현재 위치를 확인하도록 구성했습니다.
- 현재 위치에서 가까운 영화 촬영지를 거리순으로 정렬합니다.
- 탐색 반경을 **1km, 2km, 5km, 10km, 20km** 중에서 선택할 수 있도록 했습니다.
- 반경 내 장소만 보기 및 위치 필터 해제 기능을 추가했습니다.
- 위치 권한 거부, 위치 확인 실패, 시간 초과 등에 대한 안내를 개선했습니다.
- 거리 표시는 **직선거리**이며 실제 도보·차량 이동 거리 또는 이동 시간이 아닙니다.
- 주소·좌표가 확인되지 않은 촬영지는 임의의 위치에 지도 마커를 찍지 않도록 했습니다.

### 3.7 부산 지역별 촬영지

- 부산 **16개 구·군**을 선택하여 촬영지를 탐색하도록 했습니다.
- 지역별 촬영지 카드에 장소명, 연결된 영화명, 주소를 표시하도록 구성했습니다.
- `지도에서 보기`, `영화 검색` 동작을 제공합니다.
- 촬영지 목록이 길어지는 문제를 완화하기 위해 **페이지당 24개**씩 표시하는 페이지 이동 UI를 추가했습니다.
- 주소 확인 과정에 병렬 조회 방식을 적용했습니다.

### 3.8 철거·폐업 촬영지 제외

방문할 수 없는 장소가 일반 촬영지와 함께 표시되지 않도록, 공공데이터에 다음과 같이 명시된 장소를 제외하는 필터를 추가했습니다.

- `[철거]`, `[폐업]`, `[폐점]`
- `철거됨`, `철거완료`, `영업종료`, `운영종료`, `영구폐쇄` 등

적용 대상은 영화별 촬영지, 주변 촬영지, 지역별 촬영지입니다.

**한계:** 공공데이터에 철거·폐업 사실이 기재되지 않은 경우까지 자동으로 확인할 수는 없습니다.

### 3.9 중복 촬영지 통합 및 장소별 전체 영화 연결

기존에는 동일한 장소가 **영화별로 별도의 카드**로 반복되어 표시되는 문제가 있었습니다. 예를 들어 `감천2동 주택가`, `감천항` 등이 여러 작품에 연결될 수 있습니다.

장소 통합 및 연결 방식:

1. 동일한 장소명과 주소를 가진 촬영 기록은 **촬영지 카드 하나**로 합칩니다.
2. 하나의 촬영지에 연결된 **모든 영화 제목**을 함께 보여줍니다.
3. 어떤 영화를 검색해 해당 촬영지에 들어왔더라도, **그 장소에서 촬영된 다른 영화들**도 확인할 수 있도록 합니다.
4. 촬영지에서 다른 영화 제목을 선택하면 해당 영화 검색으로 이동할 수 있도록 합니다.
5. 이름이 같더라도 주소나 실제 위치가 다르면 별도 장소로 유지합니다.
6. 철거·폐업 장소 제외 규칙은 유지합니다.

## 4. 프로젝트 구조(주요 파일)

```text
cinespot-busan-starter/
├── .env                         # 프론트엔드 환경 변수 (공유 금지)
├── package.json                 # 프론트엔드 의존성/스크립트
├── src/
│   ├── App.jsx                  # 검색, 지도, 촬영지 탐색, 포스터 검색 UI
│   └── style.css                # UI 스타일
└── backend/
    ├── .env                     # 백엔드 API 키 (공유 금지)
    ├── main.py                  # FastAPI 엔드포인트 및 데이터 처리
    ├── poster_matcher.py        # 등록 포스터 이미지 비교
    ├── sync_poster_folders.py   # 영화별 포스터 폴더 동기화
    ├── requirements.txt        # Python 의존성
    ├── data/                    # 작품 분류 자료
    └── posters/                 # 영화별 기준 포스터 이미지
```

## 5. 실행 방법 (Windows PowerShell / VS Code)

**전제:** 프로젝트 루트 폴더를 VS Code로 열고, Python 및 Node.js가 설치되어 있어야 합니다.

### 5.1 최초 설치 또는 의존성 변경 시

백엔드 터미널:

```powershell
cd backend
python -m pip install -r requirements.txt
```

프로젝트 루트 터미널:

```powershell
npm install
```

새 ZIP을 다른 폴더에 압축 해제해 `node_modules` 또는 Python 가상환경이 없는 경우 설치가 다시 필요할 수 있습니다.

### 5.2 평소 실행 (터미널 2개)

**터미널 1 — 백엔드** (프로젝트 루트에서 실행):

```powershell
cd backend
python -m uvicorn main:app --reload --port 8000
```

**터미널 2 — 프론트엔드** (프로젝트 루트에서 실행):

```powershell
npm run dev
```

- 프론트엔드: `http://localhost:5173`
- 백엔드 API 문서: `http://127.0.0.1:8000/docs`

### 5.3 포스터 폴더 동기화 (필요할 때만)

백엔드가 실행 중인 상태에서 다른 터미널로:

```powershell
cd backend
python sync_poster_folders.py
```

이 명령어는 **매번 실행할 필요가 없습니다**. 백엔드가 꺼져 있으면 연결 거부 오류가 발생할 수 있습니다.

## 7. 확인된 문제와 해결 내역

| 현상 | 확인된 원인 / 조치 |
| --- | --- |
| `sync_poster_folders.py` 실행 시 WinError 10061 | 로컬 백엔드 연결 거부. 백엔드를 먼저 실행한 후 스크립트 실행 |
| 포스터 검색 시 `Failed to fetch` 및 HTTP 500 | 백엔드 응답 직렬화 오류 확인 |
| `numpy.int64 object is not iterable` | NumPy 결과를 Python 기본 자료형으로 변환하도록 포스터 매처 수정 |
| 포스터 인식 결과에 이미지 거리·비교 횟수 표시 | 기술적 수치를 숨기고 영화 제목 및 확인 안내만 표시 |
| 검색창 `+` 아이콘 정렬 불량 | SVG 아이콘 및 중앙 정렬 스타일 적용 |
| 철거된 촬영지 표시 | 철거·폐업 표기 필터 추가 |
| 같은 장소가 여러 영화에 대해 중복 표시 | 장소 기준 병합 및 관련 영화 전체 표시 방식 적용 |

## 8. 검증 및 개선 과제

- [ ] 429개 작품을 KOFIC 등 공식 자료로 대조하여 영화 여부 최종 검증
- [ ] 동일 제목의 다른 작품을 제작연도·감독·영화코드로 구분
- [ ] 영화별 부산 촬영 사실 및 촬영지 주소의 출처 확인
- [ ] 철거·폐업 정보가 누락된 장소에 대한 최신 상태 확인
- [ ] 동일 장소의 주소 표기 차이, 좌표 오차, 이름 차이에 대한 중복 병합 검증
- [ ] 영화 검색 → 촬영지 → 그 장소의 모든 영화 표시까지 브라우저 통합 테스트
- [ ] 현재 위치 권한 거부·주소 미확인·공공 API 오류 상황 테스트
- [ ] 포스터 인식의 오인식·미등록 포스터 안내 문구 및 UX 점검
- [ ] 브라우저/모바일 화면에서 반응형 UI 확인

## 9. 데이터 정확성과 서비스 원칙

1. **영화만 다룹니다.** 드라마·시리즈·예능은 영화 검색에 포함하지 않습니다.
2. **촬영지는 실제 공공데이터에 근거해야 합니다.** 영화 제목만 보고 촬영 장소를 추측하지 않습니다.
3. **주소가 불확실하면 잘못된 지도 핀을 생성하지 않습니다.**
4. **철거·폐업으로 표시된 장소는 방문 추천에서 제외합니다.**
