# 2026-11-22 추천 영화·주변 맛집 운영정보 작업

## 변경 내용

- 부산 촬영 영화 추천: 개봉일 기준 최신순, 국내 누적 관객수 기준 인기순 TOP 10.
- 영화 개봉일·관객수 자료 수집과 추천 목록의 자동 갱신 처리.
- 근처 맛집의 요일별 영업시간·휴무일·휴게시간을 텍스트 카드로 표시.
- 확인된 시간표에 한해 시간표 기준 영업 상태를 표시하고, 미확인 장소는 방문 전 확인 안내.
- 장소 상호·주소 대조, 지점명·영문 약자 표기 차이, 자정 이후 영업시간 처리 개선.
- 직접 입력한 운영정보의 서버 저장 및 관리자 편집키 처리.
- 갈 만한 장소·주변 주차장의 운영정보 칸 제거. 장소 선택·지도·코스 기능 유지.
- 확인한 일부 장소 제외와 상호 정정, 촬영지 중복 정리.

## 제공 범위

운영시간은 수집·저장된 장소에 한해 제공합니다. 전체 주변 장소의 수집이 완료된 것은 아닙니다.
인기순 상위 영화 주변 맛집을 우선 확인했습니다. 시간표를 확인하지 못했다고 폐업을 뜻하지 않습니다.
시간표 기준 영업 상태는 예상이며 임시휴무·공휴일·현장 변경과 다를 수 있습니다.
실시간 위치는 브라우저 권한과 각 지도 서비스 설정이 필요합니다.

## 공유한 운영정보

`backend/data/shared_operating_info.json`에는 저장된 시간표와 연결 정보, 서버에 직접 입력한 운영정보만 담습니다.
원본 SQLite DB·진행 대기열·실패 기록·편집키는 공유하지 않습니다.
백엔드 시작 때 공유 자료를 로컬 DB에 가져옵니다. 기존 로컬의 더 최신 시간표·관리자 수정은 보존합니다.
필요하면 `python operating_info_exchange.py`로 직접 가져올 수 있습니다.
브라우저에만 저장된 개인 코스·최근 기록·개인 입력은 포함하지 않습니다.

## 실행 방법 — Windows PowerShell

루트 `.env.example`을 `.env`로, `backend/.env.example`을 `backend/.env`로 복사하고 각자의 키를 설정합니다.
이 파일들은 값이 비어 있는 예시입니다. 실제 키·편집키를 Git에 올리지 않습니다.

프런트엔드:

```powershell
npm.cmd ci
npm.cmd run dev
```

백엔드 — 별도 터미널:

```powershell
cd backend
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

운영시간을 새로 수집하려면 Playwright 패키지와 Microsoft Edge가 필요합니다.
기존 공유 시간표 표시와 새 브라우저 수집은 구분됩니다.

```powershell
.\.venv\Scripts\python.exe -m pip install playwright
```

## 환경변수

| 파일 | 변수 | 목적 |
|---|---|---|
| 루트 `.env` | `VITE_KAKAO_JAVASCRIPT_KEY` | 카카오 지도·주변 검색 |
| 루트 `.env` | `VITE_API_BASE_URL` | 백엔드 주소, 로컬 기본값 `http://127.0.0.1:8000` |
| `backend/.env` | `MOVIE_API_GET_URL`, `MOVIE_API_KEY` | 영화 촬영지 공공데이터 |
| `backend/.env` | `CINEMAP_API_GET_URL`, `CINEMAP_API_KEY` | 씨네맵 촬영지 공공데이터 |
| `backend/.env` | `KOBIS_API_KEY` | 영화 정보 갱신 |
| `backend/.env` | `OPERATING_INFO_EDIT_TOKEN` | 운영정보 관리자 수정, 각 실행 환경에서 별도 설정 |
| `backend/.env` | `NAVER_HEADLESS` | 수집 브라우저 표시 여부, 기본 `true` |
| `backend/.env` | `TOUR_API_KEY`, `BUSAN_PARKING_API_KEY` | 기존 공공데이터 조회 기능을 사용할 때의 선택 설정 |

영화 API 주소와 카카오 JavaScript 허용 도메인은 각 발급 서비스의 설정을 확인합니다.
개인 PC용 키 값은 README나 예시 파일에 포함하지 않습니다.

## 확인할 동작

팀원이 다른 PC에서 실행한 뒤 다음을 확인합니다. 아래 항목은 확인 지침이며 자동으로 통과했다고 주장하는 기록이 아닙니다.

- 최신순·인기순에 각각 최대 10개 영화와 해당 기준이 표시되는지.
- 영화 선택 후 촬영지·주변 장소 선택과 코스 생성이 되는지.
- 수집된 맛집 시간표가 보이고, 미확인 장소에 확인 안내가 보이는지.
- 갈 만한 장소·주차장의 운영정보 칸이 없는지.
- 공유 자료를 가져온 뒤 기존 로컬 관리자 수정이 유지되는지.
